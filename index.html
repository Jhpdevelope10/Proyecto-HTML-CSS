Sobre mí

Soy un desarrollador backend en formación, motivado y enfocado en construir sistemas técnicos funcionales y bien estructurados. Me interesa especialmente el ecosistema de Node.js, las APIs REST, la monitorización de datos y la arquitectura de aplicaciones. Mi objetivo es crecer profesionalmente creando soluciones limpias, eficientes y escalables.

Proyectos

NodeTrack API

API REST desarrollada con Node.js, Express y MySQL. Incluye endpoints CRUD para gestionar usuarios, roles y estados, con validación básica y estructura organizada en controladores, rutas y servicios.

DataPulse Dashboard

Panel administrativo minimalista para monitorizar métricas simuladas en tiempo real. Backend en Node.js y frontend con gráficos limpios usando Chart.js.

TaskFlow Admin

Sistema de gestión de tareas con Node.js, Express y SQLite. CRUD completo, panel administrativo simple y filtrado por estado y prioridad.

HabitSync

Aplicación personal para seguimiento de hábitos. Backend con Node.js y Express, almacenamiento en JSON local y una interfaz minimalista corporativa.
